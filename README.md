# Les rutes de la promesa 🧭

**Joc interactiu sobre els patriarques d'Israel i la cultura jueva, per a 1r d'ESO.**

El joc inclou sis missions amb preguntes, mapes, símbols, objectes, festes, reflexions, punts d'experiència i insígnies. L'aplicació és en català.

## ▶️ Com obrir el joc

**Enllaç previst de GitHub Pages:** https://jbv1980.github.io/jonathanbv1980.github.io/

Si el lloc ja s'ha publicat correctament, en obrir l'enllaç es mostrarà el joc. No cal tenir un compte de GitHub per jugar.

## ⚙️ Com activar o comprovar GitHub Pages

1. Obre el [repositori](https://github.com/JBV1980/jonathanbv1980.github.io).
2. A la barra superior, selecciona **Settings** (*Configuració*).
3. Al menú lateral, fes clic a **Pages** (*Pàgines*). També hi pots entrar directament des de [Configuració de Pages](https://github.com/JBV1980/jonathanbv1980.github.io/settings/pages).
4. A **Build and deployment** (*Compilació i desplegament*), busca **Source** (*Origen*) i selecciona **Deploy from a branch** (*Desplega des d'una branca*).
5. A **Branch** (*Branca*), selecciona **main**.
6. A **Folder** (*Carpeta*), selecciona **/ (root)** (*carpeta arrel*).
7. Prem **Save** (*Desa*).
8. Comprova a l'apartat **Pages** si apareix el missatge que el web està publicat i l'opció **Visit site** (*Visita el lloc*). Si el desplegament encara s'està executant, consulta la pestanya **Actions** (*Accions*).

> **Nota sobre l'idioma:** els noms dels botons de GitHub poden aparèixer en anglès. Les traduccions en català d'aquesta guia indiquen què vol dir cada opció, però no canvien l'idioma de la interfície de GitHub.

## 🧑‍🏫 Com utilitzar-lo amb l'alumnat

1. Comparteix l'enllaç del joc a Classroom, Moodle o al teu entorn virtual.
2. Demana a cada alumne que creï un **codi inventat**, sense introduir-hi el nom real, i que indiqui el grup.
3. L'alumnat pot completar les missions al seu ritme. El joc permet reprendre la partida i reiniciar-la.
4. Per recollir evidències d'avaluació, fes que exportin el progrés des del joc en format **JSON** o l'informe de reptes en **CSV**.
5. Per revisar diversos resultats al mateix navegador, consulta l'apartat **Docent** del joc i les opcions d'importació disponibles.

## 🔒 Privacitat i conservació del progrés

- El joc és una pàgina web estàtica, i **GitHub no recull automàticament les notes dels alumnes**.
- Les dades de la partida es desen al **navegador del dispositiu** mitjançant emmagatzematge local (*localStorage*).
- Si un alumne canvia de dispositiu, esborra les dades del navegador o utilitza una finestra privada, el progrés pot no estar disponible. Cal exportar els resultats abans.
- Per prudència, utilitza codis pseudònims i **no hi escriguis dades personals identificatives**.

## 🛠️ Si l'enllaç no funciona

1. Obre [Settings → Pages](https://github.com/JBV1980/jonathanbv1980.github.io/settings/pages) i comprova que la font sigui **main** i la carpeta **/ (root)**.
2. Revisa a [Actions](https://github.com/JBV1980/jonathanbv1980.github.io/actions) que el desplegament de Pages no hagi fallat.
3. Comprova que el fitxer `index.html` sigui a l'arrel de la branca `main`.
4. Torna a obrir l'enllaç de GitHub Pages després que GitHub confirmi que el lloc s'ha publicat.
